# Web Programming — Movie Review Page

Homework 2 from the GSU Web Programming course: a movie review page for *TMNT (2007)* in the style of Rotten Tomatoes, built with semantic HTML and CSS.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

## What's on the page

- Banner and overall "rotten" rating with score
- Two-column layout of critic reviews, each with a fresh or rotten icon and the critic's name and publication
- Sidebar with a general overview of the film
- W3C HTML and CSS validation badges

## View it

Open `HW2/tmnt.html` in a browser.
